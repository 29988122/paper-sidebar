# 紙白側欄（Paper Sidebar）商店資訊（繁體中文）

**名稱**（取自 manifest）：紙白側欄
**摘要**（取自 manifest，≤132 字）：全白的垂直分頁，目前分頁左側有一條橘色標記。簡潔的配色主題，不需任何權限。

## 詳細說明

紙白側欄讓 Chrome 原生的垂直分頁變得乾淨、清爽，像一張白紙。

• 分頁側欄、工具列、視窗外框全白，沒有一整片灰色
• 目前分頁的圖示左邊有一條橘色標記
• 分頁標題為清楚的黑色，其他分頁保持平整、不搶眼
• 分頁群組保留 Chrome 原本鮮明的群組顏色
• 不論系統是淺色或深色模式，外觀都一致

開啟垂直分頁：在任一分頁上按右鍵 →「垂直顯示分頁」。

注意事項
• 這是主題：沒有程式碼、不需任何權限、不收集任何資料。
• 滑鼠移到分頁上時，那個分頁也會暫時出現橘色標記。
• 分頁群組顏色、字型、列高由 Chrome 自行繪製。
• 無痕視窗不會套用主題。
• 在「自訂 Chrome」中選擇顏色，會取代這個主題。
• 移除方式：設定 → 外觀 → 主題 →「重設為預設值」。
